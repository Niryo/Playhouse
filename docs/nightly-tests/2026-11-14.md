## Product changes (visible to users)

1. **The Plugin Catalog's Token Stats comparison page showed only its title** (regression from #252, merged
   after the 11-13 round). `sample-token-stats.json` lacked the `contextCompactions` and `resumeCacheMisses`
   keys that the native model gained, so decoding failed with `keyNotFound` and the page rendered empty. The
   sample now carries both, and `catalog/TokenStats.js` renders the compaction and "Resume cache miss · …"
   lines the way native `TokenStatsView` does. Contract, CLI case (`cases_21.py`) and UI case for
   `test_plugin_token_stats_renders_from_atoms_like_native` assert the new lines.
2. Two new diagnostics events, no behaviour change:
   - `plugin.catalog.page_failed` (page, error) whenever a catalog page's sample fails to load. The eight
     `try? Self.sample(...)` sites in `PluginCatalogView.swift` now go through `catalogValue`.
   - `conversation.follow_bottom.stopped` (old/new offset and max offset, pin and reveal flags) when the
     transcript stops following the latest message.

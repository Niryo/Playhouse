## Failures and repairs

### Shared Git fixture leaked state

The first full run failed `test_done_archive_displays_existing_pull_request_link`,
`test_review_pr_conflicts_probe_and_verify`, `test_review_sync_pushes_unpushed_changes_on_completion`,
and `test_review_sync_resolves_conflicts_with_provider_or_blocks`.

`test_task_pr_conflicts_detect_without_mutation` added an `origin` remote to the shared primary
fixture and committed a target-branch change, but left both behind. Later cases therefore saw
an existing remote and a changed merge target. The test now records the original target commit,
removes `origin`, and hard-resets the owned fixture to that commit in `defer`; its bare remote
is under the per-case directory. The ordered PR cases passed 6/6 after the repair, and the final
full suite passed.

### Claude wake control observation

`test_claude_background_shell_keeps_turn_open_through_wake` once observed the Pause control
missing while the early woken-turn result was held. Bridge diagnostics show the provider
process and logical turn remained active until the fixture's 30-second guard timed out, so the
turn had not actually settled. The case then passed alone, with its neighboring background-agent
case, in the original 8-case batch, and in the final full suite. Its assertion and timeout were
left intact. Treat this as a load-sensitive UI observation to monitor; no product regression was
reproduced.
